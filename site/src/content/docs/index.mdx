Browser Recorder is a browser extension for Chrome and Firefox that captures
console output, network activity, interactions, DOM snapshots, screenshots, and
optional video, then bundles the selected evidence into a portable `.zip`.

**No account, telemetry, or upload service.** Captures use browser-managed local
storage; exports are files under your control. Exports can contain sensitive page
data, and request replay sends a real, potentially authenticated request.

## What you get

A session export is named
`browser-recording-{title-or-host}-{YYYYMMDD-HHmm}.zip` by default. It contains
a self-contained `report.html` viewer and the selected artifacts that were
actually captured.

Capture-time filtering removes credential-like headers and redacts recognised
sensitive URL/body fields. Export review can additionally redact detected
fields, remove complete requests from every report artifact, or exclude
artifacts. Automated checks do not make screenshots, DOM, video, replay, or
other captured content safe to share.

Experimental session replay best-effort masks native input values and editable
text before replay events leave the page. This is not comprehensive redaction:
other page content and separate DOM, screenshot, and video captures can still be
sensitive.

## Quick start

1. Open the popup and click **Start session** (or press **Alt+Shift+R**).
2. Reproduce the bug; use **Pause**/**Resume**, capture controls, or **Discard session** as needed.
3. Open the popup and click **Stop & report** (or press **Alt+Shift+S**).
4. Edit and review the report, then click **Export ZIP**.

For an unplanned problem, turn on **Continuous capture → Always on**. Its
five-minute default window is limited by the configured site scope; enabling it
with the default empty allowlist pins the focused host for the current browser
session. Click **Export** to review the retained window. An explicit session
suspends all continuous capture until it stops or is discarded.

Download the browser-specific
`browser-recorder-<version>-chrome.zip` or
`browser-recorder-<version>-firefox.zip` from
[GitHub Releases](https://github.com/HabitatHQ/browser-recorder/releases).
Firefox requires version 128 or newer.
